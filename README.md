# Omega-chat（全能线）

一个 d512 通用小模型，目标是全能型小强：什么都懂一点、什么都能试、
什么都不精。学而不精是设计，不是失败。最终目标是用户自己的本地 agent，
这个模型是通向它的练习件。

## 训练方式

300 步一块，每块存自己的产品，下一块用 `--init` 只取参数热启动
（优化器与学习率曲线全新）；被重启杀掉时用 `--resume` 从 25 步断点
续跑。产品是 195 MB 的 `.npz`，不进仓库，只留在工作台。
